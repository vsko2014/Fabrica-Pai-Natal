# 🎄 FPN — Fábrica do Pai Natal

**A little Christmas magic, powered by code. 🎁**

FPN is a Christmas gift wishlist web application built for my family, providing a shared space to save and explore gift ideas throughout the year.

Developed as a personal project to practise software engineering, explore modern web technologies, and build something useful with the support of AI.

## ✨ Features

- 🎁 Create and manage personal gift wishlists.
- 👨‍👩‍👧‍👦 Explore gift suggestions from family members.
- 🖼️ Add images, prices, and product links.
- 🔎 Preview product images fetched from a product URL before choosing to save them.
- 🔐 Private authentication and access control.
- 📱 Responsive interface with a Christmas-inspired design.

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Authentication:** Better Auth
- **Database:** PostgreSQL, Supabase
- **ORM:** Drizzle ORM
- **Validation:** Zod
- **Testing:** Playwright
- **Deployment:** Vercel
- **Development:** AI-assisted development 🤖

## 🎯 Purpose

Beyond its practical use, FPN is an opportunity to apply full-stack development concepts, explore secure authentication and data persistence, and learn by building a real-world application.
